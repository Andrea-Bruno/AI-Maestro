# Руководство по Внешним Инструментам

Maestro AI поддерживает подключение внешних лабораторных и цеховых инструментов через USB (Serial / HID) для мониторинга в реальном времени во время обжарки.

## Поддерживаемые Инструменты

| Инструмент | Измерение | Подключение | Протокол | Типичные Модели |
|-----------|-----------|-------------|----------|-----------------|
| **Манометр** | Давление газа (кПа) | USB Serial | Modbus RTU / 4-20mA | Dwyer 626, Wika S-10, Omega PX409 |
| **Анемометр** | Скорость воздуха (м/с) | USB Serial | Modbus RTU / 0-10V | Dwyer VF-H100, Testo 425, Extech SDL350 |
| **Вариак** | Напряжение (В) | USB Serial | Аналог 0-250В → АЦП | Staco 3PN1010, вариак с USB вольтметром |
| **RPM Барабана** | Обороты барабана | USB Pulse | Датчик Холла / энкодер | Monarch PLT200, оптический тахометр |
| **Гигрометр** | Влажность воздуха (%RH) | USB HID | HID / I2C | Sensirion SHT35, BME280, DHT22 через USB |
| **Детектор CO** | Угарный газ (ppm) | USB Serial | Modbus RTU | CO2Meter CM-100, Spec Sensors 110-102, MQ-7 |
| **Тестер Влажности** | Влажность зелёного зерна (%) | USB Serial | Резистивный / ёмкостной | John Deere SW08120, AgriTronix, AD7745 |
| **Барометр** | Атмосферное давление (гПа) | USB Serial / HID | I2C / Modbus RTU | BME280, BMP390, MS5611 через USB |

## Конфигурация

Добавить в `appsettings.json`:

```json
"Instruments": {
  "Enabled": false,
  "GasManometer": { "Enabled": false, "Port": "COM5", "BaudRate": 9600, "AlarmHighKpa": 8.0 },
  "AirflowMeter": { "Enabled": false, "Port": "COM6", "BaudRate": 9600 },
  "CoDetector": { "Enabled": false, "Port": "COM10", "BaudRate": 9600, "AlarmThresholdPpm": 50 },
  "Barometer": { "Enabled": false, "Port": "COM12", "BaudRate": 9600 }
}
```

Каждый инструмент имеет:
- `Enabled`: true для активации
- `Port`: COM-порт (Windows) или /dev/ttyUSB0 (Linux)
- `BaudRate`: скорость последовательного порта (по умолчанию 9600)
- Специфические параметры: диапазон давления, пороги тревоги и т.д.

## Безопасность — Сигнализация CO

Когда датчик CO превышает `AlarmThresholdPpm` (по умолчанию 50 ppm):
- Вкладка Обжарка показывает красный значок "⚠️ CO ALARM"
- Панель инструментов отображает состояние тревоги
- Сигнализация сохраняется в течение 5 минут после последнего показания

**Критический порог** (200 ppm): немедленно эвакуировать помещение.

## Схема Подключения USB

| Инструмент | USB-адаптер | Подключение |
|-----------|-------------|-------------|
| Манометр (4-20mA) | USB-4750 | Сигнал+ → AI, GND → GND |
| Анемометр (0-10V) | USB-4704 | Сигнал → AI, GND → GND |
| CO (UART) | CP2102 | TX→RX, RX→TX, VCC→5V, GND→GND |
| Гигрометр (I2C) | USB-I2C | SDA, SCL, VCC, GND |
| Барометр (I2C) | USB-I2C | SDA, SCL, VCC, GND |

## Устранение Неисправностей

| Симптом | Вероятная Причина | Решение |
|---------|------------------|---------|
| Инструмент "отключён" | Неправильный COM-порт | Проверить порт в диспетчере устройств |
| Инструмент "ошибка" | Неправильная скорость | Убедиться, что скорость совпадает с устройством |
| Значения на нуле | Проблема с проводкой | Проверить сигнал и заземление |
| Ложная тревога CO | Прогрев датчика | Подождать 60 сек после включения |

## Альтернатива GPIO

Все перечисленные инструменты также могут быть подключены через **GPIO** вместо USB-последовательного порта с использованием [52Pi EP-0129 GPIO 40-PIN Hat](https://wiki.52pi.com/index.php?title=EP-0129) на Raspberry Pi. Полезно для интеграции датчиков непосредственно в контроллер обжарки.

| Инструмент | Альтернатива GPIO | Датчик | Pin |
|-----------|------------------|--------|-----|
| Манометр газа | 4-20mA → АЦП → SPI | ADS1115 / MCP3008 | GPIO9-11 (SPI) |
| Измеритель потока | 0-10V → АЦП → SPI | ADS1115 | GPIO9-11 (SPI) |
| Об/мин барабана | Датчик Холла → GPIO input | KY-003 / A3144 | GPIO21 |
| Гигрометр | I2C → SDA/SCL | BME280 / SHT35 | GPIO2 (SDA), GPIO3 (SCL) |
| Барометр | I2C → SDA/SCL | BMP390 / MS5611 | GPIO2 (SDA), GPIO3 (SCL) |
| Измеритель влажности | Ёмкостной → АЦП → SPI | AD7745 / MCP3008 | GPIO9-11 (SPI) |

> **Примечание:** Чтение инструментов через GPIO требует активного драйвера GPIO (`MachineType: "52Pi EP-0129 GPIO 40-PIN Hat"`). См. [09-hardware.md](09-hardware.md#gpio--sbc-40-pin-raspberry-pi--orange-pi) для подключения и настройки.
