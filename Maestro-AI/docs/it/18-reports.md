# Reports

Genera report HTML dai dati di tostatura.

## Report Tostatura

Report singolo con: nome profilo, origine, data, operatore, metriche DTR/AUC/tempo/perdita peso, punteggio cupping.

## Report Produzione

Riepilogo multi-lotto: totale lotti, caffè verde consumato, perdita media.

## Generazione

Seleziona un profilo e clicca **Roast Report** o **Production Report**.
