# Importazione ed Esportazione

Formati supportati: Maestro JSON (.maestro) e .alog (.alog).

## Importazione

1. Incolla il contenuto nel textarea
2. Inserisci il nome file con estensione
3. Clicca Import

## Esportazione

1. Seleziona il profilo
2. Scegli il formato
3. Clicca Export

Il formato .alog include curve temperatura, eventi, peso, umidità, colore e UUID.
