# Batches & Production

Track and report on roasting production.

## Batch Counter

The batch counter auto-increments each time a roast is saved. You can:
- **Set** the counter to any value (e.g., reset at the start of each day)
- The counter is **persistent** across restarts

## Register a Batch

When registering a completed batch, record:

| Field | Description |
|-------|-------------|
| Profile Name | Which roast profile was used |
| Bean Origin | Coffee origin (e.g., Ethiopia Yirgacheffe) |
| Green Weight | Weight of green coffee before roasting (g) |
| Roasted Weight | Weight after roasting (g) |
| Moisture Loss | Measured moisture loss percentage |
| Whole Color | Agtron whole bean color reading |
| Ground Color | Agtron ground coffee color reading |
| Defects Weight | Weight of defective beans removed |

## Production Report

The production report shows:

- **Total batches** processed
- **Total green coffee** consumed (kg)
- **Average weight loss** percentage across all batches

Each batch record includes origin, weight in/out, loss %, color readings, and operator name.
