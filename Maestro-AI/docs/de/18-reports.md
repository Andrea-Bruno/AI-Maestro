# Reports

Generate HTML reports from roast data.

## Roast Report

A single-roast report including:
- Profile name, bean origin, date, operator
- Metrics: DTR, AUC, total roast time, weight loss
- Cupping score (if available)

## Production Report

A multi-batch production summary showing:
- Total batches processed
- Total green coffee consumed
- Average weight loss

## Generating Reports

1. Select a **profile** from the dropdown
2. Click **Roast Report** or **Production Report**
3. The report appears as an HTML page in an embedded viewer

Reports can be printed or saved as HTML files from the browser.
