Dashboard — Startbildschirm

Das Dashboard ist das Erste, was Sie sehen, wenn Sie Maestro AI öffnen. Es gibt Ihnen einen schnellen Überblick über alles: Läuft der Server, wie viele Röstungen wurden gespeichert, wie viele laufen gerade? Betrachten Sie es als das Fenster zum Kontrollraum.

Was Sie auf dem Dashboard sehen

AnzeigeWas sie Ihnen sagt
Aktive SitzungenWie viele Röstungen laufen gerade auf dem Server. Wenn die Zahl größer als 0 ist, röstet gerade jemand (oder Sie selbst).
Gespeicherte ProfileWie viele Röstprofile auf dem Server gespeichert sind. Jedes Profil ist eine vollständige Aufzeichnung einer Röstung mit Temperaturen, Zeiten und Ereignissen.
ServerzeitAktuelles Datum und Uhrzeit des Maestro AI Servers. Wird alle 30 Sekunden aktualisiert, damit Sie immer wissen, dass der Server läuft.
BetriebszeitWie lange der Server ohne Unterbrechung seit dem letzten Neustart läuft. Eine hohe Zahl bedeutet, dass das System stabil ist.

Status-LED

Oben auf jedem Bildschirm sehen Sie eine kleine grüne oder rote LED. Grün bedeutet, der Server ist verbunden und arbeitet. Rot bedeutet, die Verbindung ist unterbrochen — prüfen Sie, ob der Maestro AI Server läuft und ob die URL in den Einstellungen korrekt ist.

Letzte Röstung

Die Box unten zeigt den Namen der zuletzt gespeicherten Röstung. Wenn Sie noch keine Röstungen durchgeführt haben, werden Sie freundlich zum Start aufgefordert.

Betriebsmodi

Maestro AI bietet drei Nutzungsarten. Sie wählen den Modus im Einstellungen-Panel.

ModusWann verwenden
ÜberwachungNur-Lesen-Modus. Das Diagramm folgt jeder laufenden Röstung auf dem Server, aber Sie können nichts starten oder stoppen. Perfekt für einen zweiten Bildschirm oder um die Röstung eines Kollegen zu beobachten.
EinfachDie vereinfachte Ansicht. Zeigt nur die wichtigsten Steuerungen für die Röstung und die wesentlichen Panels. Ideal, wenn Sie neu bei Maestro AI sind oder einen sauberen, fokussierten Bildschirm wünschen.
VollAlles ist sichtbar. Jedes Panel, jeder Knopf, jede erweiterte Funktion. Verwenden Sie dies, wenn Sie KI-Profile, zusätzliche Sensoren, digitale Signaturen oder Energieanalyse benötigen.
Die grüne LED oben bedeutet, der Server ist online. Bleibt sie rot, gehen Sie zu den Einstellungen und prüfen Sie die Server-URL.
