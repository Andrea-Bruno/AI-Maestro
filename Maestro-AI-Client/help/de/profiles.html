Profile — Ihre Röstbibliothek

Das Profile-Panel verwaltet alle gespeicherten Röstungen. Jedes Mal, wenn Sie eine Röstung beenden, wird sie zu einem Profil — einer vollständigen Aufzeichnung mit Temperaturen, Zeiten, Ereignissen und Notizen. Betrachten Sie es als eine Bibliothek aller Röstungen, die Sie je durchgeführt haben.

Profilliste

Wenn Sie den Reiter Profile öffnen, sehen Sie eine Liste aller gespeicherten Profile. Klicken Sie auf einen Profilnamen, um es anzuzeigen. Die Aktualisierungsschaltfläche lädt die Liste vom Server neu (nützlich, wenn ein anderer Computer ein neues Profil gespeichert hat).

AktionAusführung
Profil anzeigenKlicken Sie auf den Namen. Es wird im Analyse-Panel geladen, wo Sie alle Zahlen sehen können.
Profil löschenNur im Vollmodus. Klicken Sie auf die X-Schaltfläche neben dem Profilnamen, um es dauerhaft zu entfernen.

Zielkurven-Designer

Vor dem Start einer Röstung können Sie eine ideale Temperaturkurve entwerfen. Geben Sie vier Schlüsselpunkte ein, und Maestro AI zeichnet eine Referenzlinie, der Sie während der Röstung folgen können.

EingabeBedeutung
Charge TempDie Temperatur der Trommel beim Einladen des Kaffees.
TrocknungsendeDie gewünschte Temperatur am Ende der Trocknungsphase (Bohnen wechseln von grün zu gelb, etwa 160°C).
FC BeginnDie Temperatur, bei der der First Crack stattfinden soll (normalerweise 190–200°C).
DropDie Temperatur, bei der Sie die Bohnen entnehmen möchten.

Drücken Sie Ziel Erstellen, und die Referenzkurve erscheint während Ihrer Röstung als lila gepunktete Linie im Diagramm.

Phasenbereiche

Sie können Maestro AI mitteilen, welche Temperaturen den Beginn jeder Phase markieren. Dies hilft dem System, korrekt zu erkennen, wann die Bohnen in die Trocknungs-, Maillard- und Entwicklungsphase eintreten. Wenn Ihre Maschine heisser oder kälter läuft, verbessert die Anpassung dieser Bereiche die Phasenerkennung.

Eigenschaften

Wenn Sie ein Profil laden, können Sie seine Eigenschaften bearbeiten: Einwaage und Auswaage (zur Berechnung des Verlusts) und die Ganzbohnenfarbe (Agtron-Wert). Diese Zahlen werden mit dem Profil gespeichert und im Analyse-Panel verwendet.

Transformator

Manchmal haben Sie ein Profil, das mit einer anderen Chargengrösse oder Maschine erstellt wurde, und möchten es anpassen. Der Transformator ermöglicht Folgendes:

OperationFunktion
ZeitskalierungDie Zeitachse dehnen oder stauchen. Nützlich, wenn die ursprüngliche Röstung 10 Minuten dauerte und Ihre 12 Minuten benötigt.
Temp-OffsetAlle Temperaturen um einen festen Betrag nach oben oder unten verschieben. Nützlich, wenn Ihre Maschine 5°C heisser läuft als das Original.
InvertierenDie Kurve umkehren (selten verwendet, aber praktisch für spezielle Analysen).
C → FAlle Temperaturen von Celsius in Fahrenheit umrechnen.

Import und Export

Sie können Profile aus anderen Programmen importieren oder Ihre Profile mit anderen teilen.

So importieren Sie ein Profil:

  • Ziehen Sie eine .maestro-, .alog- (Artisan) oder .json-Datei per Drag & Drop in die Ablagezone.
  • Oder klicken Sie auf die Import-Schaltfläche, um eine Datei von Ihrem Computer auszuwählen.
  • Oder fügen Sie den Dateiinhalt in das Textfeld ein.

So exportieren Sie ein Profil: Wählen Sie ein Format (JSON oder .alog), wählen Sie das zu exportierende Profil aus und drücken Sie Export. Verwenden Sie dies, um Ihre Profile zu sichern oder mit anderen Röstern zu teilen.

Artisan-Profile (.alog) werden beim Import automatisch konvertiert — alle Ereignisse und Temperaturdaten bleiben erhalten.

Digitale Signatur

Im Vollmodus können Sie Ihre Profile mit einer digitalen Signatur versehen. Dies garantiert, dass das Profil von Ihnen erstellt und nicht manipuliert wurde. Sie benötigen einen privaten Schlüssel zum Signieren, und jeder mit Ihrem öffentlichen Schlüssel kann die Signatur überprüfen. Nützlich für Wettbewerbe oder den professionellen Austausch von Profilen.
