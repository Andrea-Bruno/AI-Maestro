Einstellungen — Maestro AI konfigurieren

Im Einstellungen-Panel legen Sie fest, wie Maestro AI mit dem Server verbunden wird, welche Sprache es spricht, wie es Temperaturen misst und wer die Einstellungen ändern kann.

Serververbindung

Maestro AI muss mit einem Server kommunizieren, um Profile zu speichern und die Hardware zu steuern. Geben Sie hier die Serveradresse ein.

SituationEingabe
Maestro AI läuft auf demselben Computer wie dieser Bildschirmhttp://localhost:5252 (dies ist die Standardeinstellung)
Maestro AI auf einem anderen Computer in Ihrem Netzwerkhttp://192.168.1.XXX:5252 — verwenden Sie die IP-Adresse des Server-Rechners
Maestro AI in einem anderen NetzwerkSie müssen Port-Weiterleitung auf Ihrem Router einrichten und die öffentliche IP verwenden
Nach dem Ändern der Server-URL versucht die Seite, sich neu zu verbinden. Bleibt die LED oben rot, überprüfen Sie, ob der Server läuft und ob Ihre Firewall Verbindungen auf Port 5252 zulässt.

Sprache

Wählen Sie die Sprache für die Benutzeroberfläche. Alle Schaltflächen, Beschriftungen und Hilfetexte wechseln in die ausgewählte Sprache. Derzeit unterstützt: Englisch, Italienisch, Französisch, Deutsch, Spanisch, Russisch.

Temperatureinheit

Wählen Sie zwischen Celsius (°C) und Fahrenheit (°F). Die meisten Kaffeeröster verwenden Celsius, aber wenn Sie Fahrenheit gewohnt sind, stellen Sie es hier um.

GUI-Modus

Maestro AI hat drei Oberflächenmodi. Wählen Sie den, der zu dem passt, was Sie tun.

ModusAm besten geeignet für
ÜberwachungBeobachten einer Röstung, ohne etwas zu berühren. Das Diagramm wird live aktualisiert, aber es werden keine Schaltflächen zum Starten oder Stoppen angezeigt. Gut für einen zweiten Bildschirm oder eine öffentliche Anzeige.
EinfachTägliches Rösten. Zeigt nur die wichtigsten Bedienelemente: Röst-Panel, Profilliste, Diagnose und Einstellungen. Die erweiterten Funktionen (KI, zusätzliche Sensoren, Signieren usw.) sind ausgeblendet.
VollAlles. Alle Panels, alle Schaltflächen, alle erweiterten Funktionen. Verwenden Sie dies, wenn Sie KI-Profilgenerierung, zusätzliche Kanäle, digitale Signaturen, Energieanalyse, BBP, Cloud-Dienste, Spektroskopie und Hybridheizung benötigen.

PIN-Schutz

Sie können das Einstellungen-Panel mit einer 4- bis 6-stelligen PIN schützen. Dies verhindert, dass jemand während einer Röstung versehentlich die Server-URL ändert oder den Modus wechselt.

PIN festlegen: Geben Sie eine neue PIN in beide Felder ein und drücken Sie Speichern. Beim nächsten Öffnen der Einstellungen muss die PIN eingegeben werden.

PIN entfernen: Lassen Sie das Feld "Neue PIN" leer und drücken Sie Speichern.

Standard-PIN: 0000 (falls Sie sie nie geändert haben).

Wenn Sie Ihre PIN vergessen haben, öffnen Sie die Browser-Konsole (F12) und geben Sie ein: localStorage.setItem('maestro-pin',''). Damit wird die PIN zurückgesetzt.

UI-Skalierung

Die Oberfläche vergrössern oder verkleinern. Verwenden Sie Gross, wenn Sie einen Touchscreen, ein hochauflösendes Display verwenden oder wenn Sie den Bildschirm aus der Ferne betrachten.

Diagnose-Reiter — Systemzustand prüfen

Der Diagnose-Reiter zeigt Ihnen den Gesundheitszustand Ihres Maestro AI Systems. Nutzen Sie ihn, um zu überprüfen, ob alles funktioniert, oder um Probleme zu finden.

Systemstatus

Die Hauptstatuskarte zeigt drei Dinge:

AnzeigeBedeutung
ServerGrünes Licht bedeutet, der Maestro AI Server läuft und antwortet. Rot bedeutet, der Server ist offline oder nicht erreichbar.
GerätGrünes Licht bedeutet, die Hardware (Röster, Sensoren) ist verbunden. Rot bedeutet, kein Gerät erkannt — überprüfen Sie Kabel und Stromversorgung.
BetriebszeitWie lange der Server seit dem letzten Start läuft. Hilfreich zu wissen, ob das System kürzlich abgestürzt oder neu gestartet wurde.

Gerätetest

Drücken Sie Gerät Testen, um einen schnellen Kommunikationstest mit der angeschlossenen Hardware durchzuführen. Das Ergebnis erscheint im untenstehenden Ereignisprotokoll. Wenn der Test fehlschlägt, überprüfen Sie die Hardwareanschlüsse und starten Sie den Server neu.

Notstopp

Die rote Notstopp-Schaltfläche ist nur für Notfälle vorgesehen. Wenn Sie sie drücken, wird:

  • Die gesamte Hardware sofort getrennt (Heizung, Sensoren, Trommelmotor).
  • Jede aktive Röstsitzung gestoppt.
  • Das Ereignis im Diagnoseprotokoll aufgezeichnet.

Ein Bestätigungsdialog fragt, ob Sie sicher sind, bevor der Vorgang ausgeführt wird. Dies ist nicht dasselbe wie das normale Beenden einer Röstung — verwenden Sie DROP und ENDE im Röst-Panel für den normalen Abschluss.

Ereignisprotokoll

Das Protokoll unten zeigt eine Liste der letzten Ereignisse: Serverstarts, Gerätetests, API-Aufrufe, Fehler und Notstopps. Jeder Eintrag hat einen Zeitstempel. Nutzen Sie dies, um Probleme zu diagnostizieren oder zu sehen, was passiert ist, während Sie weg waren. Drücken Sie die Aktualisierungsschaltfläche, um neue Einträge zu laden.
