Settings — How to Configure Maestro AI

The Settings panel is where you set up how Maestro AI connects to the server, what language it speaks, how hot it measures things, and who can change the settings.

Server Connection

Maestro AI needs to talk to a server to save profiles and control the hardware. Enter the server address here.

SituationWhat to enter
Maestro AI running on the same computer as this screenhttp://localhost:5252 (this is the default)
Maestro AI on another computer in your networkhttp://192.168.1.XXX:5252 — use the IP address of the server machine
Maestro AI on a different networkYou need to set up port forwarding on your router and use the public IP
After changing the server URL, the page tries to reconnect. If the LED at the top stays red, check that the server is running and that your firewall allows connections on port 5252.

Language

Choose the language for the interface. All buttons, labels, and help texts will switch to your selected language. Currently supported: English, Italian, French, German, Spanish, Russian.

Temperature Unit

Choose between Celsius (°C) and Fahrenheit (°F). Most coffee roasters use Celsius, but if you are used to Fahrenheit, change it here.

GUI Mode

Maestro AI has three interface modes. Choose the one that fits what you are doing.

ModeBest for
MonitoringWatching a roast without touching anything. The chart updates live, but no buttons to start or stop are shown. Good for a second screen or a public display.
EasyDaily roasting. Shows only the controls you need most: roast panel, profile list, diagnostics, and settings. The advanced features (AI, extra sensors, signing, etc.) are hidden.
FullEverything. All panels, all buttons, all advanced features. Use this when you need AI profile generation, extra channels, digital signatures, energy analysis, BBP, cloud services, spectroscopy, and hybrid heating.

PIN Protection

You can protect the Settings panel with a 4-to-6 digit PIN. This prevents someone from accidentally changing the server URL or switching modes during a roast.

Setting a PIN: Enter a new PIN in both fields and press Save. The next time someone tries to open Settings, they will need to enter the PIN first.

Removing the PIN: Leave the "New PIN" field empty and press Save.

Default PIN: 0000 (if you never changed it).

If you forget your PIN, open the browser console (F12) and type: localStorage.setItem('maestro-pin',''). This resets the PIN to none.

UI Scale

Make the interface larger or smaller. Use Large if you are using a touchscreen, a high-resolution display, or if you are viewing the screen from a distance.

Diagnostics Tab — Checking the System Health

The Diagnostics tab shows you the health of your Maestro AI system. Use it to check if everything is working or to find problems.

System Status

The main status card shows three things:

ItemWhat it tells you
ServerA green light means the Maestro AI server is running and responding. Red means the server is offline or unreachable.
DeviceA green light means the hardware (roaster, sensors) is connected. Red means no device is detected — check cables and power.
UptimeHow long the server has been running since it was last started. Helpful to know if the system recently crashed or was restarted.

Test Device

Press Test Device to run a quick communication test with the connected hardware. The result appears in the event log below. If the test fails, check the hardware connections and restart the server.

Emergency Stop

The red Emergency Stop button is for urgent situations only. Pressing it will:

  • Immediately disconnect all hardware (heater, sensors, drum motor).
  • Stop any active roast session.
  • Log the event in the diagnostics log.

A confirmation dialog will ask if you are sure before proceeding. This is not the same as ending a roast normally — use DROP and END in the Roast panel for normal completion.

Event Log

The log at the bottom shows a list of recent events: server starts, device tests, API calls, errors, and emergency stops. Each entry has a timestamp. Use this to diagnose problems or to see what happened while you were away. Press the refresh button to load new entries.
