Dashboard — Home Screen

The Dashboard is the first thing you see when you open Maestro AI. It gives you a quick overview of everything: is the server running, how many roasts have been saved, how many are happening right now. Think of it as the control room window.

What you see on the Dashboard

ItemWhat it tells you
Active SessionsHow many roasts are currently running on the server. If you see a number higher than 0, someone (or you) is roasting right now.
Saved ProfilesHow many roast profiles are stored on the server. Each profile is a complete record of a roast you did, including temperatures, times, and events.
Server TimeThe current date and time of the Maestro AI server. This refreshes every 30 seconds so you always know the server is alive.
UptimeHow long the server has been running without interruption since the last restart. A high number means the system is stable.

Status LED

At the top of every screen you see a small green or red light (LED). Green means the server is connected and working. Red means the connection is lost — check that the Maestro AI server is running, and that the URL in Settings is correct.

Last Roast

The box at the bottom shows the name of the most recent roast you saved. If you haven't done any roasts yet, it will politely tell you to start one.

Operating Modes

Maestro AI has three ways you can use it. You choose the mode in the Settings panel.

ModeWhen to use it
MonitoringLook-only mode. The chart follows whatever roast is happening on the server, but you cannot start or stop anything. Perfect for a second screen or when you want to watch a colleague's roast.
EasyThe simplified view. Shows only the essential controls for roasting and the most important panels. Great if you are new to Maestro AI or just want a clean, focused screen.
FullEverything is visible. Every panel, every button, every advanced feature. Use this when you need AI profiles, extra sensors, digital signatures, or energy analysis.
The green LED at the top means the server is online. If it stays red, go to Settings and check that the Server URL is correct.
