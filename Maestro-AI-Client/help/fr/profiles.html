Profils — Votre Bibliothèque de Torréfactions

Le panneau Profils est l'endroit où vous gérez toutes les torréfactions que vous avez sauvegardées. Chaque fois que vous terminez une torréfaction, elle devient un profil — un enregistrement complet avec températures, temps, événements et notes. Considérez-le comme une bibliothèque de chaque torréfaction que vous avez jamais faite.

Liste des Profils

Quand vous ouvrez l'onglet Profils, vous voyez une liste de tous les profils sauvegardés. Cliquez sur un nom de profil pour le voir. Le bouton d'actualisation recharge la liste depuis le serveur (utile si un autre ordinateur a sauvegardé un nouveau profil).

Depuis la liste vous pouvez :

ActionComment faire
Voir un profilCliquez sur son nom. Il se charge dans le panneau Analyse où vous pouvez voir tous les chiffres.
Supprimer un profilUniquement en mode Complet. Cliquez sur le bouton X à côté du nom du profil pour le supprimer définitivement.

Concepteur de Courbe Cible

Avant de commencer une torréfaction, vous pouvez concevoir une courbe de température idéale. Entrez quatre points clés et Maestro AI dessine une ligne de référence que vous pouvez suivre pendant la torréfaction.

Point à entrerCe que ça signifie
Temp ChargementLa température du tambour quand vous chargez le café.
Fin SéchageLa température souhaitée à la fin de la phase de séchage (le café passe du vert au jaune, vers 160°C).
Début FCLa température où vous voulez que le Premier Crack se produise (généralement autour de 190–200°C).
DropLa température à laquelle vous prévoyez de sortir les grains.

Appuyez sur Créer Cible et la courbe de référence apparaît sur le graphique pendant votre torréfaction sous forme de ligne violette pointillée.

Plages de Phases

Vous pouvez indiquer à Maestro AI quelles températures marquent le début de chaque phase. Cela aide le système à identifier correctement quand les grains entrent dans les phases de Séchage, Maillard et Développement. Si votre machine fonctionne plus chaud ou plus froid, ajuster ces plages rend la détection de phase plus précise.

Propriétés

Quand vous chargez un profil, vous pouvez modifier ses propriétés : poids d'entrée et de sortie (pour calculer la perte), et la couleur du grain entier (valeur Agtron). Ces chiffres sont sauvegardés avec le profil et utilisés dans le panneau Analyse.

Transformateur

Parfois vous avez un profil qui a été fait avec une taille de lot ou une machine différente, et vous voulez l'adapter. Le Transformateur vous permet de :

OpérationCe qu'elle fait
Échelle TempsÉtirer ou réduire l'axe temporel. Utile si la torréfaction originale durait 10 minutes et que la vôtre doit durer 12.
Décalage TempDécaler toutes les températures vers le haut ou le bas d'un montant fixe. Utile si votre machine est 5°C plus chaude que l'originale.
InverserRetourner la courbe (rarement utilisé, mais pratique pour des analyses spéciales).
C → FConvertir toutes les températures de Celsius en Fahrenheit.

Importation et Exportation

Vous pouvez importer des profils depuis d'autres programmes ou partager vos profils avec d'autres.

Pour importer un profil :

  • Glissez-déposez un fichier .maestro, .alog (Artisan) ou .json sur la zone de dépôt.
  • Ou cliquez sur le bouton Importer pour sélectionner un fichier sur votre ordinateur.
  • Ou collez le contenu du fichier dans la zone de texte.

Pour exporter un profil : choisissez un format (JSON ou .alog), sélectionnez le profil à exporter et appuyez sur Exporter. Utilisez ceci pour sauvegarder vos profils ou les partager avec un autre torréfacteur.

Les profils Artisan (.alog) sont automatiquement convertis lors de l'importation — toutes les données de température et d'événements sont préservées.

Signature Numérique

En mode Complet, vous pouvez signer vos profils avec une signature numérique. Cela garantit que le profil a été créé par vous et n'a pas été modifié. Vous avez besoin d'une clé privée pour signer, et toute personne possédant votre clé publique peut vérifier la signature. Utile pour les compétitions ou lors du partage professionnel de profils.
