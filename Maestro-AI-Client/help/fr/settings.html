Paramètres — Comment Configurer Maestro AI

Le panneau Paramètres est l'endroit où vous configurez la connexion de Maestro AI au serveur, la langue, l'unité de température, et qui peut modifier les réglages.

Connexion au Serveur

Maestro AI doit communiquer avec un serveur pour sauvegarder les profils et contrôler le matériel. Entrez l'adresse du serveur ici.

SituationQue saisir
Maestro AI sur le même ordinateur que cet écranhttp://localhost:5252 (valeur par défaut)
Maestro AI sur un autre ordinateur du réseauhttp://192.168.1.XXX:5252 — utilisez l'adresse IP du serveur
Maestro AI sur un réseau différentVous devez configurer le redirection de ports sur votre routeur
Après avoir changé l'URL du serveur, la page tente de se reconnecter. Si le voyant LED reste rouge, vérifiez que le serveur fonctionne et que votre pare-feu autorise les connexions sur le port 5252.

Langue

Choisissez la langue de l'interface. Tous les boutons, étiquettes et textes d'aide passeront dans la langue sélectionnée. Actuellement pris en charge : anglais, italien, français, allemand, espagnol, russe.

Unité de Température

Choisissez entre Celsius (°C) et Fahrenheit (°F). La plupart des torréfacteurs utilisent Celsius, mais si vous êtes habitué à Fahrenheit, changez-le ici.

Mode GUI

Maestro AI propose trois modes d'interface. Choisissez celui qui correspond à ce que vous faites.

ModeIdéal pour
SurveillanceRegarder une torréfaction sans toucher à rien. Le graphique se met à jour en direct, mais aucun bouton pour démarrer ou arrêter n'est affiché. Bon pour un deuxième écran.
FacileTorréfaction quotidienne. Affiche seulement les contrôles dont vous avez le plus besoin. Les fonctions avancées sont masquées.
CompletTout. Tous les panneaux, tous les boutons, toutes les fonctions avancées : profils IA, capteurs supplémentaires, signatures numériques, analyse énergétique, BBP, cloud, spectroscopie, chauffage hybride.

Protection par PIN

Vous pouvez protéger le panneau Paramètres avec un code PIN à 4 à 6 chiffres. Cela empêche quelqu'un de modifier accidentellement l'URL du serveur ou de changer de mode pendant une torréfaction.

Définir un PIN : Entrez un nouveau PIN dans les deux champs et appuyez sur Enregistrer.

Supprimer le PIN : Laissez le champ « Nouveau PIN » vide et appuyez sur Enregistrer.

PIN par défaut : 0000 (si vous ne l'avez jamais changé).

Si vous oubliez votre PIN, ouvrez la console du navigateur (F12) et tapez : localStorage.setItem('maestro-pin',''). Cela réinitialise le PIN.

Échelle UI

Agrandissez ou réduisez l'interface. Utilisez Grande si vous utilisez un écran tactile, un écran haute résolution, ou si vous regardez l'écran à distance.

Diagnostic — Vérifier la Santé du Système

L'onglet Diagnostic montre l'état de votre système Maestro AI. Utilisez-le pour vérifier si tout fonctionne ou pour trouver des problèmes.

État du Système

La carte d'état principale montre trois choses :

ÉlémentCe qu'il indique
ServeurUn voyant vert signifie que le serveur Maestro AI est en cours d'exécution et répond. Rouge signifie qu'il est hors ligne ou inaccessible.
PériphériqueUn voyant vert signifie que le matériel (torréfacteur, capteurs) est connecté. Rouge signifie qu'aucun périphérique n'est détecté.
Temps de fonctionnementDepuis combien de temps le serveur tourne depuis son dernier démarrage. Utile pour savoir si le système a récemment planté.

Tester le Périphérique

Appuyez sur Tester pour lancer un test de communication rapide avec le matériel connecté. Le résultat apparaît dans le journal d'événements ci-dessous.

Arrêt d'Urgence

Le bouton rouge Arrêt d'Urgence est réservé aux situations urgentes. Appuyer dessus va :

  • Déconnecter immédiatement tout le matériel (chauffage, capteurs, moteur du tambour).
  • Arrêter toute session de torréfaction active.
  • Enregistrer l'événement dans le journal de diagnostic.

Une boîte de dialogue de confirmation demandera si vous êtes sûr avant de procéder. Ceci n'est pas la même chose que terminer une torréfaction normalement — utilisez DROP et END dans le panneau Torréfaction pour une fin normale.

Journal d'Événements

Le journal en bas montre une liste des événements récents : démarrages du serveur, tests de périphérique, appels API, erreurs et arrêts d'urgence. Chaque entrée a un horodatage. Utilisez-le pour diagnostiquer les problèmes ou voir ce qui s'est passé en votre absence.
