Ajustes — Cómo Configurar Maestro AI

El panel Ajustes es donde configuras cómo Maestro AI se conecta al servidor, qué idioma usa, cómo mide la temperatura y quién puede cambiar los ajustes.

Conexión al Servidor

Maestro AI necesita hablar con un servidor para guardar perfiles y controlar el hardware. Ingresa la dirección del servidor aquí.

SituaciónQué ingresar
Maestro AI en el mismo ordenador que esta pantallahttp://localhost:5252 (valor por defecto)
Maestro AI en otro ordenador de tu redhttp://192.168.1.XXX:5252 — usa la dirección IP del servidor
Maestro AI en una red diferenteDebes configurar el reenvío de puertos en tu router
Después de cambiar la URL del servidor, la página intenta reconectarse. Si el LED permanece rojo, verifica que el servidor esté funcionando y que tu cortafuegos permita conexiones en el puerto 5252.

Idioma

Elige el idioma de la interfaz. Todos los botones, etiquetas y textos de ayuda cambiarán al idioma seleccionado. Actualmente compatibles: inglés, italiano, francés, alemán, español, ruso.

Unidad de Temperatura

Elige entre Celsius (°C) y Fahrenheit (°F). La mayoría de los tostadores usan Celsius, pero si estás acostumbrado a Fahrenheit, cámbialo aquí.

Modo GUI

Maestro AI tiene tres modos de interfaz. Elige el que se ajuste a lo que estás haciendo.

ModoMejor para
MonitoreoObservar un tostado sin tocar nada. El gráfico se actualiza en vivo, pero no se muestran botones para iniciar o detener. Bueno para una segunda pantalla.
FácilTostado diario. Muestra solo los controles que más necesitas. Las funciones avanzadas están ocultas.
CompletoTodo. Todos los paneles, todos los botones, todas las funciones avanzadas: perfiles IA, sensores extra, firmas digitales, análisis energético, BBP, nube, espectroscopia, calefacción híbrida.

Protección por PIN

Puedes proteger el panel Ajustes con un PIN de 4 a 6 dígitos. Esto evita que alguien cambie accidentalmente la URL del servidor o el modo durante un tostado.

Establecer un PIN: Ingresa un nuevo PIN en ambos campos y presiona Guardar.

Eliminar el PIN: Deja el campo «Nuevo PIN» vacío y presiona Guardar.

PIN predeterminado: 0000 (si nunca lo cambiaste).

Si olvidas tu PIN, abre la consola del navegador (F12) y escribe: localStorage.setItem('maestro-pin',''). Esto restablece el PIN.

Escala UI

Haz la interfaz más grande o más pequeña. Usa Grande si usas una pantalla táctil, una pantalla de alta resolución, o si ves la pantalla desde lejos.

Diagnóstico — Comprobando la Salud del Sistema

La pestaña Diagnóstico muestra la salud de tu sistema Maestro AI. Úsala para verificar si todo funciona o para encontrar problemas.

Estado del Sistema

La tarjeta de estado principal muestra tres cosas:

ElementoQué te indica
ServidorUna luz verde significa que el servidor Maestro AI está funcionando y respondiendo. Rojo significa que está fuera de línea o inaccesible.
DispositivoUna luz verde significa que el hardware (tostador, sensores) está conectado. Rojo significa que no se detecta ningún dispositivo.
Tiempo ActivoCuánto tiempo lleva el servidor funcionando desde su último inicio. Útil para saber si el sistema se ha reiniciado recientemente.

Probar Dispositivo

Presiona Probar para ejecutar una prueba rápida de comunicación con el hardware conectado. El resultado aparece en el registro de eventos debajo.

Parada de Emergencia

El botón rojo Parada de Emergencia es solo para situaciones urgentes. Al presionarlo:

  • Desconecta inmediatamente todo el hardware (calefacción, sensores, motor del tambor).
  • Detiene cualquier sesión de tostado activa.
  • Registra el evento en el registro de diagnóstico.

Aparecerá un diálogo de confirmación preguntando si estás seguro. Esto no es lo mismo que terminar un tostado normalmente — usa DROP y END en el panel Tostado para finalizar normalmente.

Registro de Eventos

El registro en la parte inferior muestra una lista de eventos recientes: inicios del servidor, pruebas de dispositivo, llamadas API, errores y paradas de emergencia. Cada entrada tiene una marca de tiempo. Úsalo para diagnosticar problemas o ver qué sucedió mientras no estabas.
